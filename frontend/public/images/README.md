# Image Asset Structure

Keep real photography grouped by use and property.

## Brand

Place Patricia's future profile or brand image in:

```text
brand/patricia/patricia.jpeg
```

Adjust the filename later only if the real source file needs a different format.

## Properties

Place property photographs in numbered property folders until the final property grouping is confirmed:

```text
properties/property-01/
properties/property-02/
properties/property-03/
properties/property-04/
properties/property-05/
```

Recommended filenames when the photo subject is clear:

```text
hero.jpeg
living-room.jpeg
bedroom-01.jpeg
bedroom-02.jpeg
kitchen.jpeg
bathroom.jpeg
dining.jpeg
balcony.jpeg
exterior.jpeg
```

Do not force these names if the real photograph shows a different space. Use clear, lowercase, hyphenated filenames.

The current fallback image remains:

```text
property-hero.jpeg
```
